# SAG Workbench

A browser page for reading and checking **SAG** (Statistical Analysis Graphs) diagrams: type or paste a plain-text SAG description and see the diagram, the validator's findings, and the underlying maths. Its **Learn** tab holds the training manual (lessons, practical exercises with live checking, and a reference to symbols, syntax, grammar and glossary).

This is a **generated build**, published here only so colleagues can open it without a GitHub or Claude account. The source of truth — the language specification, the tool, and the decision log — lives in the private `sag-language` repository. Nothing in this repo is hand-edited; it is rebuilt and pushed here from `tools/build_web.py` whenever the tool changes.

**Live page:** https://ariesconsultkenya.github.io/sag-tools/ (once GitHub Pages is turned on for this repo: Settings → Pages → Source: Deploy from a branch → `main` / `(root)`).
